1. PhilGPT

Project landing page here.

PhilGPT is a small RAG-pipeline which periodically scrapes and updates a knowledge base of information from the transcripts of all episodes of the PhilosophizeThis! podcast.

You can either clone the repository and run a version of this app locally, or you can have an ephemeral interaction with PhilGPT on the very barebones hosted WebUI: PhilGPT (online).
